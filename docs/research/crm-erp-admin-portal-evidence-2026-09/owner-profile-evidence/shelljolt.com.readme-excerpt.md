# ShellJolt — the cockpit for your AI coding CLIs

**[shelljolt.com](https://shelljolt.com)** · Live product · Source private (commercial product)

One live line showing **cost · context · usage-limits · model** across Claude Code, Codex, Gemini,
and Grok, with a supervisor that protects your Mac. ShellJolt forecasts a usage limit before it
stops you, and its warn-and-ask watchdog fires *before* an AI-CLI run OOMs and freezes the machine.

## What it does

- **Cross-CLI cockpit**: one consistent live status line for every AI coding CLI you run
- **Memory protection**: adaptive per-session engine; true hard caps where the OS allows, warn-and-ask everywhere else; never closes your terminals or IDE
- **Live observability**: RAM/CPU + cost dashboard with multi-session budgeting
- **OS-level, tool-agnostic**: a shell layer every terminal inherits

## Stack

Rust · Zsh · Ed25519 device licensing · Next.js backend · Stripe
