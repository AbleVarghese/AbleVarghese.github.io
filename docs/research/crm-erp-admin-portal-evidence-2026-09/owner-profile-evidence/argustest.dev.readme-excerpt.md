# ArgusTest — give your AI eyes on iOS

**[argustest.dev](https://argustest.dev)** · Live product · Source private (commercial product)

Professional iOS device monitoring and AI-assisted debugging for developers using Claude Code,
Cursor, and other AI-powered IDEs. Real-time visibility into device state, errors, crashes, and
screenshots, delivered straight to your AI assistant through Model Context Protocol (MCP).

## What it does

- **100% app-agnostic**: monitor ANY iOS app with zero host-app modifications
- **One-command setup**: an interactive wizard detects devices, apps, and existing configs
- **Continuous log streaming** with pattern-based auto-error detection and rate limiting
- **SHA-256 error deduplication**: 78% noise reduction on real-world error streams
- **Hardened by design**: HMAC-SHA256 webhook verification, environment-based secrets, audit logging, self-healing watchdog daemons

Distributed via [Homebrew tap](https://github.com/AbleVarghese/homebrew-tap).

## Stack

TypeScript · Swift · Shell · MCP · pymobiledevice3 · Supabase · Sentry integration
